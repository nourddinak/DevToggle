# Contributing to DevToggle

First off, thank you for considering contributing to DevToggle! It's people like you that make DevToggle such a great tool for the Android developer community.

## How Can I Contribute?

### Reporting Bugs
This section guides you through submitting a bug report for DevToggle. Following these guidelines helps maintainers and the community understand your report, reproduce the behavior, and find related reports.
* Use the **Bug Report** issue template.
* Provide clear steps to reproduce the issue.

### Suggesting Enhancements
This section guides you through submitting an enhancement suggestion for DevToggle, including completely new features and minor improvements to existing functionality.
* Use the **Feature Request** issue template.
* Detail the motivation for the feature.

### Your First Code Contribution
1. Fork the repo and create your branch from `master`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code lints.

## Pull Requests
The process described here has several goals:
- Maintain DevToggle's quality
- Fix problems that are important to users
- Engage the community in working toward the best possible DevToggle
- Enable a sustainable system for DevToggle's maintainers to review contributions

Please follow these steps to have your contribution considered by the maintainers:
1. Follow all instructions in the template
2. After you submit your pull request, verify that all status checks are passing.
